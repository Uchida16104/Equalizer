About Equalizer Studio

Equalizer Studio is a production-ready, browser-based audio equalizer and FFT visualizer designed for people with auditory hypersensitivity, low voice volume, or real-time frequency-based audio control needs.

It analyzes microphone input in real time using a 2048-point FFT, applies a 7-band parametric filter bank with per-band gain control, and renders a live spectrum visualization using p5.js with detected frequency peaks annotated directly on the canvas.

Built with Next.js, p5.js, Alpine.js, HTMX, hyperscript, and Tailwind CSS. No backend audio processing — all computation runs in the browser via the Web Audio API and optional Web Workers.
